# idealauncher

A Minecraft Launcher made by Denzi

## Feature

1. **Support selecting the GPU used in Minecraft**.
2. Basic Function for **install Minecraft** and **launch Minecraft**.
3. Support **Mod Loader** installation.
4. Support **Multiple Accounts**.

## Development

### Install

```bash
$ pnpm install
```

### Launch IdeaLauncher

```bash
$ pnpm dev
```

### Build

```bash
# For windows
$ pnpm build:win

# For macOS
$ pnpm build:mac

# For Linux
$ pnpm build:linux
```
